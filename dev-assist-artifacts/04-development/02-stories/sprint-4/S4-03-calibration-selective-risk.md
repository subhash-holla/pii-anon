## 1. Intent
**AX-005** mandates **calibrated abstention**: every finding must carry a calibrated confidence (not a bare logit), and the system must report *per-class* calibration quality + a *selective-risk* (risk-coverage) profile so a deployer can pick an abstention operating point. Today the eval framework has only **global** ECE/MCE + a `TemperatureScaler`; there is **no per-class ECE, no Brier, no AURC, no abstention operating-point table, and no calibrated-confidence-coverage audit**. The SDO **G4** guarantee (calibration / selective-risk) is therefore a hardcoded PENDING placeholder.

This story (a) ships a `SelectiveRiskReporter` computing per-entity-class **ECE / Brier / AURC + reliability** and a ≥3-point **abstention operating-point** table, plus a **calibrated-confidence-coverage** check (NFR-020: 100% findings carry calibrated confidence + provenance, 0 bare-logit), and (b) makes the SDO **G4** guarantee **code-computable**: the gate reads pii-anon's per-class calibration + selective-risk + confidence-coverage and emits PASS/FAIL/PENDING (three-valued, no fabrication), replacing the placeholder. This completes G4 in the SDO sense: the guarantee logic is LIVE + teeth-tested; a TRUE verdict (like every guarantee) is gated on the S7 canonical run.

## 2. Approach / scope
- **`selective_risk.py` — the reporter (reuses, doesn't re-derive).** `SelectiveRiskReporter` consumes scored predictions (per-finding `confidence` + correctness + `entity_type`) + a reference, and produces a `SelectiveRiskReport` carrying: **per-class ECE** (one `CalibrationReport`/`ExpectedCalibrationError` per entity type — reuse the sibling `metrics/calibration.py`), **per-class Brier** (+ decomposition, NFR-018), **per-class AURC** + the risk-coverage curve with a **monotone-non-increasing** assertion (NFR-019), an **abstention operating-point table** (≥3 rows at selective-risk targets {1%, 2%, 5%}, NFR-021), and a **calibrated-confidence-coverage** field (fraction of findings carrying a calibrated confidence + provenance; NFR-020 requires 100% / 0 bare-logit). It reuses `TemperatureScaler` for the post-scaling ECE (NFR-017: ECE_post ≤ ECE_pre; ≤ 0.05 high-resource / ≤ 0.08 long-tail).
- **`scorecard.py` — additive calibration summary fields.** Add a small set of calibration summary fields (e.g. `calibration_ece`, `selective_risk_aurc`, `calibrated_confidence_coverage`) to `SystemScorecard` + serialize in `to_dict()` (parallel to the S4-01 anon/pseudo fields). All existing fields (incl. `privacy_score` + the S4-01 `anonymization_score`/`pseudonymization_integrity_score`) untouched; `composite_score` numeric behavior unchanged.
- **`competitive_supremacy.py` — wire G4 (additive, preserve the gate).** Replace `_pending_guarantee("G4", overrides.get("G4"))` with `_g4_calibration_selective_risk(benchmark)` — a pure `(benchmark) -> GuaranteeResult` mirroring `_g1_recall_floor` / the S4-01 `_g2_pseudonymization_integrity`: **PASS** iff pii-anon's per-class ECE ≤ the NFR-017 thresholds AND AURC is monotone non-increasing AND ≥3 abstention points present AND calibrated-confidence-coverage = 100% (NFR-020); **FAIL** iff present-but-threshold-breached (binding detail names the worst class / the breach); **PENDING** (None) iff the artifact lacks the calibration fields (NO fabrication — the current smoke artifact lacks them). The verdict machine, `RecallFloorVerdictGuard`, the J-meter, the Tier-R∪Tier-C gating, the S4-01 G2 function, and RISK-6 are **untouched**; the gate's import-boundary test stays **scoped to the 2 gate modules**.
- **Reuse + boundary.** All new per-class/AURC/abstention logic lives in `selective_risk.py`; the existing `metrics/calibration.py` is **consumed unchanged** (no rewrite). `selective_risk.py` imports nothing from `swarm/moe/fusion/policy` (CI-guarded). The runtime `calibration/` package (OfflineCalibrator/OnlineCalibrator/CalibrationStore — applied to the ExpertRegistry by `orchestrator.py`) is **out of scope + byte-identical** (this story is eval REPORTING, not runtime calibration).

## 3. Given / When / Then (acceptance — concrete, testable)
- **A1 — per-class ECE `[UNIT-TEST]` (NFR-017).** **Given** a synthetic per-finding (confidence, correct, entity_type) corpus spanning ≥2 entity classes, **when** `SelectiveRiskReporter` runs, **then** it returns a **per-entity-class** ECE (distinct from the global ECE), reusing `metrics/calibration.py`; a deliberately mis-calibrated class shows a higher ECE than a well-calibrated class.
- **A2 — per-class Brier + decomposition `[UNIT-TEST]` (NFR-018).** Per-class Brier score computed; a perfectly-calibrated synthetic class → low Brier; a mis-calibrated class → higher Brier.
- **A3 — AURC + monotone risk-coverage `[UNIT-TEST]` `[PROPERTY-TEST]` (NFR-019).** Per-class AURC + the risk-coverage curve; a **property test** asserts the curve is **monotone non-increasing** in coverage (selective risk does not increase as you abstain more); AURC is lower for a better-calibrated synthetic class.
- **A4 — abstention operating-point table `[UNIT-TEST]` (NFR-021).** **Given** the scored corpus, **then** the reporter emits a **≥3-point** abstention table at selective-risk targets {1%, 2%, 5%} (each row: target risk → achieved coverage); the points are consistent with the risk-coverage curve.
- **A5 — calibrated-confidence-coverage (NFR-020, the lone MUST) `[AUDIT]` `[CONTRACT-TEST]`.** **Given** a corpus where every finding carries a calibrated confidence + provenance, **then** `calibrated_confidence_coverage == 1.0` (0 bare-logit); **given** a corpus with a bare-logit / provenance-less finding, **then** the coverage drops < 1.0 and the audit flags it (teeth — not a no-op that always reports 100%).
- **A6 — post-temp-scaling ECE (NFR-017) `[UNIT-TEST]`.** Reusing `TemperatureScaler`, **then** ECE_post ≤ ECE_pre always; the post-scaling ECE on a synthetic well-resourced class ≤ 0.05 (and the long-tail threshold 0.08 is applied to sparse classes).
- **A7 — G4 PASS/FAIL/PENDING teeth `[PROPERTY-TEST]` `[CONTRACT-TEST]`.** **Given** a SYNTHETIC benchmark fixture where pii-anon's calibration meets the NFR thresholds (per-class ECE ≤ bar ∧ AURC monotone ∧ ≥3 abstention points ∧ coverage=1.0), **then** `_g4_calibration_selective_risk` returns **PASS**; **given** a fixture breaching a threshold (e.g. a class ECE > 0.05, or coverage < 1.0) → **FAIL** (binding detail names the breach); **given** a fixture LACKING the calibration fields → **PENDING** (None, no fabrication). A teeth test verifies non-vacuity (worsening a class's ECE flips PASS→FAIL).
- **A8 — real-artifact verdict unchanged `[CONTRACT-TEST]`.** **Given** the real (smoke) benchmark artifact (lacking the calibration fields), **when** `pii-anon supremacy` runs, **then** the verdict stays **NOT_YET** with binding constraint **`canonical_claim_run=False`**, and G4 reads **PENDING** (fields absent — honest), NOT a fabricated PASS. (G4's successor label updates from "unbuilt" to "awaiting a run that emits the fields".)
- **A9 — import-boundary + determinism `[PROPERTY-TEST]`.** AST scan: `selective_risk.py` + the `_g4_*` function import nothing from `swarm/moe/fusion/policy`; two runs of the reporter on the same synthetic inputs yield equal reports (AX-002). `metrics/calibration.py` byte-identical (consumed, unchanged).
