## 1. Intent
**AX-004** is a load-bearing project axiom: anonymization (irreversible de-identification) and pseudonymization (reversible-under-controlled-key) are **structurally distinct** and must **never** be merged into a single de-id score — they answer different questions (anon: "is the original unrecoverable?"; pseudo: "is reversal authorized-only + referentially consistent + key-separated?"). The current `SystemScorecard.privacy_score` is a **single conflated field** — the AX-004 violation on the scoring surface. S3-04 already separated the **Tier-3 RRS** Davidson sub-model (`_store_state=False`, never bleeds into de-id state); this story extends that separation to the **scoring families** themselves.

This story (a) ships two **distinct** scorer families with no merge path, (b) adds a **no-merge CI guard** (the AX-004 teeth — a structural test that fails if any merged de-id field/function ever appears), and (c) makes the SDO **G2** guarantee **code-computable**: the gate now reads pii-anon's pseudonymization-integrity vs every competitor and emits PASS/FAIL/PENDING (three-valued, no fabrication), replacing the hardcoded PENDING placeholder. This completes G2 in the sense the SDO requires: the guarantee logic is LIVE + teeth-tested; a TRUE verdict (like every guarantee) is gated on the S7 canonical run.

## 2. Approach / scope
- **`deid_families.py` — the two distinct families (no merge).** `DeidFamilyScores` is a frozen record carrying `anonymization: AnonymizationScore` and `pseudonymization_integrity: PseudonymizationIntegrityScore` as **two separate sub-records** — there is NO `combined`/`deid_score`/`privacy_score` field on it. `AnonymizationScorer` aggregates the EXISTING irreversibility metrics (`ReidentificationRiskMetric`, `LeakageDetectionMetric`, `CanaryExposureMetric` from `metrics/privacy_metrics.py`) — "is the original unrecoverable?". `PseudonymizationIntegrityScorer` computes the FR-009 axes: **unauthorized-reversal rate** (NFR-014: must = 0 — a reversal succeeding without the authorized key is a failure), **referential integrity** (same plaintext → same surrogate within scope, = 100%), **collision rate**, and **key/state separation** (NFR-015: the artifact alone cannot re-join — reversal requires the external secret). The two scorers share NO mutable state and neither imports the other.
- **`scorecard.py` — additive split, backward-compatible.** Add `anonymization_score: float` + `pseudonymization_integrity_score: float` to `SystemScorecard` + serialize both in `to_dict()`. **`privacy_score` is PRESERVED** (kept as a field + in `to_dict`) for backward-compat with the checked-in leaderboard JSON + `composite_score` callers (RISK-1); document it as **deprecated/superseded** (its value continues to be whatever populates it today; it is no longer the authoritative de-id signal). `composite_score`'s numeric behavior is unchanged (it keeps reading whatever it reads today — no leaderboard regression).
- **`competitive_supremacy.py` — wire G2 (additive, preserve the gate).** Replace `_pending_guarantee("G2", overrides.get("G2"))` (line 307) with `_g2_pseudonymization_integrity(benchmark)` — a pure `(benchmark) -> GuaranteeResult` mirroring `_g1_recall_floor`/`_g3_*`: **PASS** iff pii-anon's `pseudonymization_integrity_score` STRICTLY dominates every competitor's AND unauthorized-reversal = 0 AND both family fields are present-and-distinct; **FAIL** iff present-but-not-dominant (binding detail names the gap); **PENDING** (None) iff the benchmark artifact lacks the `pseudonymization_integrity_score`/`anonymization_score` fields (NO fabrication — the current smoke artifact lacks them). The verdict machine, the `RecallFloorVerdictGuard`, the J-meter, the Tier-R/Tier-C gating, and RISK-6 are **untouched**; the gate's import-boundary test stays **scoped to the 2 gate modules** (do NOT broaden).
- **No-merge CI guard (the AX-004 teeth).** A structural/AST test asserting: (a) `DeidFamilyScores` (and the scorer modules) expose NO single field/method that merges anonymization + pseudonymization into one number (greppable/AST denylist of merged-field names + a positive assertion that both families are separately addressable); (b) `deid_families.py` imports nothing from `swarm/moe/fusion/policy` (mirrors `test_rating_import_boundary.py`); (c) the anonymization family and pseudonymization family do not import each other in a merging way. This is the standing regression gate for FR-010/AX-004.
