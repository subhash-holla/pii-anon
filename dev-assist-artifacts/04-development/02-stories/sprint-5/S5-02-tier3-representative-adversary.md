## 1. Intent
S5-01 laid the `ReidAttack` foundation with a deliberately-weak **baseline** (plain weighted-Jaccard argmax, commits on ANY non-zero overlap). S5-02 adds the **Tier-3 representative adversary** — a materially stronger, still-deterministic re-identification attacker that is the honest in-tree stand-in for the real Tier-3 LLM adversary (FR-011), plus the **RRS statistical-power machinery** (NFR-012: Wilson confidence intervals on integer success counts + the 2-rung paired-persona power ladder). Two things make it "Tier-3 representative" rather than "baseline": (1) it links on a **combined signal** — quasi-identifier combination (QIC) overlap fused with a background-signal-linkage (BSL) prior from the persona's `auxiliary_knowledge` — not a single token set; (2) it is **de-circularized** (FR-012): it commits a guess ONLY when the top candidate's similarity **margin** over the runner-up clears a threshold (so `reid_precision` is a real signal, not a vacuous argmax), and it NEVER consults the ground-truth link (a contamination control — the attack sees only the anonymized target + the candidate pool, exactly as the scorer's gold link stays out of `attack(...)`). It runs under the S5-04 sandbox, conforms to the S5-01 `ReidAttack` Protocol, and every emitted power report carries the non-strippable NFR-016 caveat.

## 2. Approach / scope — the two carried DESIGN decisions

### (a) What "Tier-3 representative" means (vs the real LLM adversary)
`RepresentativeTier3ReidAttack` (conforms to `ReidAttack`; `adversary_id="representative-tier3-reid@v1"`, `deterministic=True`):
* **QIC + BSL fused score** — for each target, `score(persona) = (1-λ)·weighted_jaccard(target_signals, persona.quasi_identifiers) + λ·bsl_prior(target_signals, persona.auxiliary_knowledge)`, where the BSL prior is a pure, deterministic overlap of target signal tokens against the persona's flattened `auxiliary_knowledge` values (background knowledge an LLM adversary would exploit). λ is a fixed module constant (the QIC/BSL blend). Reuses the S5-01 `_weighted_jaccard` shape (re-implemented locally — `reid.py` stays byte-identical; the helper is module-private there).
* **Margin-based commit/abstain (the FR-012 de-circularization control)** — the adversary commits the top persona ONLY when `(top_score - runner_up_score) ≥ MARGIN_THRESHOLD` AND `top_score > 0`; otherwise it abstains (`guessed_persona_id=None`). A single-candidate pool commits iff `top_score > 0`. This makes the adversary cautious (it does not guess on ambiguous links), so `reid_precision` measures real confidence — the inverse of the baseline's commit-on-anything.
* **Deterministic total order (AX-002)** — candidates ranked `(score DESC, persona_id ASC)`; ties resolve by `persona_id`; input-order-invariant. No `random`/`uuid`/`time`/`secrets`.
* **`# SWITCH-POINT(DATA)`/`# SWITCH-POINT(LLM)` markers** tag where the real offline DATA adversary (IDF-weighted tokens + behavioral signals) and the real LLM-call adversary plug in — both Pass-2/cross-repo. The representative adversary is the honest stand-in: stronger than baseline, fully in-tree, deterministic.

### (b) The RRS power model (NFR-012: Wilson CIs + the 2-rung ladder)
* **`wilson_interval(successes: int, n: int, *, z: float = 1.96) -> tuple[float, float]`** — the Wilson score interval for a binomial proportion on INTEGER counts (the NFR-012 "Wilson CIs" — never a normal-approx that misbehaves at the extremes). `n=0` ⇒ `(0.0, 0.0)`; clamped to `[0,1]`; pure-stdlib (`math.sqrt`), deterministic.
* **`ReidPowerCell`** (frozen) — one paired-persona cell: `cell_id`, `n_paired_personas: int`, `successes: int`, `success_rate`, `ci_low`/`ci_high` (Wilson), `rung: str` (`"REID_LOW"`/`"REID_HIGH"`), `min_required: int`, `powered: bool` (`n_paired_personas ≥ min_required`), + the non-strippable `caveat` (defaults to `ANTI_ANONYMITY_CAVEAT`, re-asserted in `__post_init__` exactly like `ReidSuccessMetrics`).
* **2-rung ladder constants** — `RRS_RUNG_REID_LOW = 385`, `RRS_RUNG_REID_HIGH = 897` (the NFR-012 literals, pinned by a contract test).
* **`assess_rrs_power(cells) -> ReidPowerLadder`** — assembles the per-cell power verdicts + an aggregate `all_powered: bool`; the ladder's `as_outcome()` carries the caveat. **The real ≥385 paired-persona cohort assembly (`assemble_paired_set`) is DATA-absent → the power-ASSERTION machinery ships now; feeding it a real cohort is the `# SWITCH-POINT(DATA)` Pass-2.**
* **Sandbox runner** `tier3_reid_attack_runner(*, targets_json, candidates_json, candidate_set_size)` — scalar JSON-string args (the `AttackSpec` rule), JSON-decode via the stdlib parser (NO unsafe-deserialization — reuses the S5-01 decode discipline), run the representative adversary, score via the S5-01 `score_reid_attack`, return `as_outcome()` (a Mapping). `TIER3_REID_ATTACK_REGISTRY = {"reid_tier3_representative": tier3_reid_attack_runner, "pii_anon.eval_framework.attacks.reid_tier3.tier3_reid_attack_runner": tier3_reid_attack_runner}` — additively merged into the sandbox default registry (disjoint keys from S5-01's; never clobbers).
